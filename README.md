# SMARTLook

This is a research project done in relation to the Department of Energy, Y-12, and the Institute for Simulation & Training at UCF. The purpose of this project is to help assist manufacturers in maintaining their SMART factories by making it easier to visualize machine vitals and schedule maintenence in a immersive web-based 3D realm.
